## 2. Upstream delta (`ef13796` → `85f45c2`, 82 commits)

- **Breaking:** the homepage now requires opt-in `layout: biography`; the theme's `layouts/index.html` was removed.
- **Breaking:** `params.colors` is nested `light:` / `dark:` with a new `background` role.
- **Breaking:** font weights are numeric; legacy `:wght@...` is only partially supported.
- **New:** light/dark mode with a toggle and a no-JS fallback (`params.color_mode`).
- **New:** build-time self-hosted Google Fonts; vendored Bootstrap CSS and Bootstrap Icons; deferred Bootstrap JS.
- **New:** hero image shape, responsive WebP processing, CLS-safe intrinsic dimensions.
- **New:** asset image processing for hero, project icons, team photos, and blog covers.
- **New:** team section page and homepage team grid; `params.team.page_title`.
- **New:** SEO partials — canonical, hreflang, description, OpenGraph/Twitter, JSON-LD (`WebSite`, `Person`, `Article`, `BreadcrumbList`).
- **New:** blog archive accordion, category cards, tag cloud, recent-post cards.
- **New:** print stylesheet, AsciiDoc admonitions/blockquotes, RTL stylesheet, `pdf-download` and `tweet-archive` shortcodes.
- **New:** `pageRef` menus, subpath-aware link rendering, `module.mounts` asset pattern.
- **New:** RSS served at `/rss/` via the theme's `hugo.yaml`.
- **New:** minimum Hugo `0.166.0`; upstream CI `0.169.0`.

```yaml
params:

    name: Miqesi
    tagline: ""
    email: "example@example.com"
    first_online: 2024
    knows_about: [ ... keep the existing list unchanged ... ]
  color_mode: auto

  fonts:

  hero:

  images:

  hire_me: false
  social:
    github: miqesi
  legal:
    license:
      name: "MPL-2.0"
      url: "https://www.mozilla.org/en-US/MPL/2.0/"

  date_format: "2006 January 02"
  team:
    page_title: "Team"
  layouts:
    categories:
      recent_posts: 3
      excerpt_length: 250
```

Notes:

- **Delete** `biography.blog: ""`.
- `social.github` takes the **username**, not a URL.
  The registry template is `https://github.com/%s`, so `miqesi` renders `https://github.com/miqesi`.
  Writing the full URL yields `https://github.com/https://github.com/miqesi`.
- `example@example.com` is the maintainer-supplied placeholder on an RFC 2606 reserved domain.
  It is valid JSON-LD and never resolves; replace it with a real address when one exists.
- `hero.shape: square` prevents the circular mask from clipping the square mark.
- `/pages/logo.png` keeps the JSON-LD `image` root-relative while `resources.Get "pages/logo.png"` resolves through the assets component.

#### 4.8 — Pin the default language

`defaultContentLang: en` is already present; keep it.
Add the weight:

```yaml
languages:
  en:
    weight: 1
    label: English
```

- `languages.*.weight` sorts `site.Languages` **ascending**, driving language-switcher and `hreflang` order.
  `1` puts English first.
- `defaultContentLang: en` is what actually pins the default content language; weight alone does not.
- Explicit weights are mandatory for deterministic multilingual builds; without them `range .AllTranslations` order varies between builds.

When adding a language later, give it weight `2` or higher and leave `defaultContentLang` alone.

### Phase 3 — Assets

#### 4.9 — Move the logo, unmodified

```bash

rmdir static/img
```

Do **not** re-encode, resize, quantize, strip metadata, or otherwise touch the bytes.
